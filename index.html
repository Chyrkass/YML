📚 Основы YAML

1. Что такое YAML?

YAML (YAML Ain't Markup Language) - это человеко-читаемый формат для сериализации данных. Используется для конфигурационных файлов, данных приложений и многого другого.

2. Базовый синтаксис

Пары ключ-значение:

ключ: значение

Списки:

- элемент1
- элемент2
- элемент3

3. Типы данных

  • Строки: name: "John"
  • Числа: age: 25
  • Булевы: active: true
  • Null: value: null

4. Вложенные структуры

YAML поддерживает сложные вложенные структуры через отступы:

person:
  name: "Alice"
  age: 30
  hobbies:
    - reading
    - swimming

5. Многострочные строки

Используйте | для сохранения переносов строк:

description: |
  Это многострочный
  текст с сохранением
  переносов строк.
